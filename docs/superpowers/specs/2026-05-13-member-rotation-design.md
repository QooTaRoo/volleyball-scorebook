# チームメンバー登録・ローテーション管理機能 設計書

## 1. 目的
バレーボールの試合記録において、スコアだけでなくコート上の選手の配置（ローテーション）とサーブ権を管理・視覚化し、選手交代をスムーズに記録できるようにする。

## 2. ユーザー体験 (UX)
- **クイックスタート**: メンバー登録なしでも「背番号1〜6」がデフォルトで配置され、すぐに利用可能。
- **直感的な操作**: コート図を模したオーバーレイで、誰がどこにいるか一目で把握。
- **自動化**: サイドアウト（サーブ権移動）時のローテーション回転を自動化し、記録者の負担を軽減。
- **一貫性**: Undo操作時もローテーション状態が正確に復元される。

## 3. 機能要件

### 3.1 メンバー管理
- **メンバー編集画面**:
    - チームA、チームBそれぞれ最大14名（例）の選手を登録可能（背番号、名前）。
    - デフォルト状態で「1」〜「6」の背番号が登録済み。
- **初期ラインナップ設定**:
    - 各セット開始前に、どの選手がどのポジション(P1〜P6)からスタートするかを選択。

### 3.2 ローテーション管理ロジック
- **サーブ権の保持**: `state.servingTeam` ('A' or 'B') で管理。
- **ポジション管理**: 各チームの `positions` 配列（長さ6）で、P1(サーバー)〜P6にいる選手のIDを保持。
- **自動回転**:
    - `servingTeam` でないチームが得点した場合：
        1. 得点したチームの `positions` を時計回りに1つずらす。
        2. `servingTeam` を得点したチームに変更。
- **手動調整**: オーバーレイ画面にて、手動での回転操作およびサーブ権の強制変更が可能。

### 3.3 UI要素
- **メイン画面**:
    - チーム名横にサーブ権を示す「🏐」アイコンを表示。
    - 各チームエリアに「コート図表示ボタン」を配置。
- **コート図オーバーレイ**:
    - 6つのポジション枠 + リベロ/ベンチ枠を表示。
    - ポジション枠タップで選手交代メニューを表示。
    - 「手動回転」ボタン（正転・逆転）。

### 3.4 データ永続化
- `localStorage` の `state` オブジェクトにメンバー情報、現在のラインナップ、サーブ権、各アクションごとのローテーション履歴を追加。

## 4. 画面設計 (UI)
- **サーブ権表示**: チーム名の横に `<span>🏐</span>` を条件付きレンダリング。
- **オーバーレイ**: `fixed inset-0` の `z-index` 高めの `div`。バレーコートのラインをCSSで表現。

## 5. 実装ステップ
1.  `state` 構造の拡張（`members`, `lineup`, `servingTeam` 等の追加）。
2.  メンバー編集用モーダルの実装。
3.  サーブ権表示と自動ローテーションロジックの追加。
4.  コート図オーバーレイの実装。
5.  Undo機能の拡張（ローテーション状態の復元）。
