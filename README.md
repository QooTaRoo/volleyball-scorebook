# 🏐 Volleyball Scorebook PWA

バレーボールの試合をスマートフォンで簡単に記録・管理できるPWA（Progressive Web App）です。
面倒なインストールは不要で、ブラウザから開いて「ホーム画面に追加」するだけですぐにネイティブアプリのように使えます。

## ✨ 主な特徴

- **スマホに最適化された巨大スコア表示**: 屋外や体育館でも見やすい、高コントラストなダークテーマ。
- **直感的な試合開始セットアップ**: 
  - 試合開始時に「対戦チーム」「試合形式（1/2/3/5セット）」「目標点数」「初回のサーブ権」をまとめて設定可能。
  - 2セットマッチ（合計得失点差での勝敗判定）などの特殊ルールにも対応。
- **タイムアウト・カウントダウンタイマー**: 
  - タイムアウト取得時に自動でタイマーがポップアップ。残り時間を視覚化し、終了時にはバイブレーションでお知らせ。
- **コート図・ローテーション管理**:
  - コート上の配置を瞬時に確認し、タップして控え選手との交代（メンバーチェンジ）も可能。
- **詳細モード (Advanced Stats Mode)**:
  - 長押し＆静止（またはスワイプ）の「一筆書き」で、得点種別（スパイク、ブロック、エース、エラー）と得点した選手を同時に記録。
  - 0.5秒の静止判定（Dwell Detection）により、落ち着いた操作が可能です。
- **メインメニュー (Navigation Hub)**: 
  - 起動時に「新規試合」「試合再開」「履歴」「設定」を俯瞰できるメニュー画面を追加。
  - 12時間以上の無操作で自動的にメニューに戻るセッションチェック機能を搭載。
- **スタッツ分析・タイムライン機能**: 
  - 各セットの得点推移グラフや、選手ごとの得点内訳を詳細に分析。
  - 試合履歴や分析結果を、1枚の画像としてLINEなどで簡単に共有。
- **データ管理（インポート/エクスポート）**:
  - 登録チームや試合履歴をJSON形式でバックアップ・復元可能。機種変更時もデータを引き継げます。
- **プロフェッショナルなUI**: 
  - `Lucide Icons` を採用し、直感的で洗練されたインターフェース。
  - 画面を極限までシンプルにするため、スコア画面のボタン類をメインメニューに集約。
  - 縦画面（対面レイアウト）と横画面（左右分割）の自動切り替えに対応。

## 📱 使い方（基本操作）

- **メインメニュー**: アプリを起動すると表示されます。「新規試合開始」で設定ダイアログに進みます。
- **スコア記録**: 自分のチームのエリアをタップすると得点が入ります。
- **詳細入力（ラジアルメニュー）**: 画面を長押しして指をずらす（一筆書き）ことで、選手別のスタッツを記録できます。
- **各種メニューへのアクセス**: スコア画面中央の「...」ボタンをタップするとメインメニューに戻ります。
- **画像シェア**: タイムラインや分析画面の「共有」ボタンから、記録を画像として保存・送信できます。

## 🚀 インストール方法 (PWA)

このアプリはPWAに対応しており、スマホのホーム画面に追加してフルスクリーンで利用できます。

### 🍎 iPhone / iPad (Safari) の場合
1. Safari でアプリの URL を開きます。
2. 画面下部の「共有」アイコン（四角から上矢印）をタップ。
3. メニューから **「ホーム画面に追加」** を選択。

### 🤖 Android (Chrome) の場合
1. Chrome でアプリの URL を開きます。
2. 画面右上の「︙（3点リーダー）」をタップ。
3. **「ホーム画面に追加」** （または「アプリをインストール」）を選択。

## 🛠️ 技術スタック

- **Core**: HTML5 / Vanilla JavaScript
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Lucide Icons
- **Libraries**: html2canvas (画像生成), Lucide (アイコン)
- **Persistence**: LocalStorage / FileReader API (バックアップ)
- **Testing**: Vitest / JSDOM (ローカルテストスイート)

## 🧪 テストの実行方法

新機能の追加やリファクタリング時にデグレードが発生しないよう、ローカルテストスイートが導入されています。

### 1. 依存関係のインストール
テスト用のモジュール（Vitest / JSDOM）をインストールします。
```bash
npm install
```

### 2. テストの実行
以下のコマンドで全23個のユニット・インテグレーションテストを実行します。
```bash
# 1回のみ実行する場合
npm run test:run

# ウォッチモード（変更監視）で実行する場合
npm run test
```
