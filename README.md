# 🏐 Volleyball Scorebook PWA

バレーボールの試合をスマートフォンで簡単に記録・管理できるPWA（Progressive Web App）です。
面倒なインストールは不要で、ブラウザから開いて「ホーム画面に追加」するだけですぐにネイティブアプリのように使えます。

## ✨ 主な特徴

- **スマホに最適化された巨大スコア表示**: 屋外や体育館でも見やすい、高コントラストなダークテーマ。
- **レスポンシブ・レイアウト**: 
  - 横画面 (Landscape): 左右分割レイアウト
  - 縦画面 (Portrait): 上下分割（対面）レイアウト。スマホを真ん中に置いてお互いに見やすい設計。
- **簡単なスコア入力**: 画面の自チームのエリアをタップするだけで加点。直感的な操作感。
- **タイムライン機能**: 各セットの得点推移やタイムアウトのタイミングを視覚的なグラフとして表示。
- **画像シェア機能**: 白熱した試合のタイムラインや過去の試合履歴を、1枚の画像としてLINEなどで簡単に共有。
- **経過タイマー**: 試合開始からの経過時間を自動計測。
- **オートセーブ**: 途中経過や設定、試合履歴はすべてブラウザ（`localStorage`）に自動保存され、リロードしても消えません。

## 📱 使い方（基本操作）

- **画面タップ**: 自分のチームのエリアをタップすると得点が入ります。
- **⚙️ (設定)**: チーム名、チームカラー、セット数、デュース有無、タイムアウト上限などのルールを設定できます。
- **↩️ (Undo)**: 直前の操作（得点やタイムアウト）を1つ取り消します。
- **↔️ (コートチェンジ)**: 画面の上下（左右）のチーム配置を入れ替えます。
- **📊 (タイムライン)**: 現在進行中のセットの得点推移グラフを確認し、「画像で共有」することができます。
- **🔄 (リセット/終了)**: 試合を途中でリセットしたり、試合結果を記録して新しい試合を始めたりします。
- **📋 (履歴)**: 過去の試合結果の一覧と、それぞれの試合の詳細なタイムラインを確認できます。

## 🚀 インストール方法 (PWA)

このアプリはPWAに対応しており、スマホのホーム画面に追加してフルスクリーンで利用できます。

### 🍎 iPhone / iPad (Safari) の場合
1. Safari でアプリの URL を開きます。
2. 画面下部のメニューバー中央にある **「共有」アイコン** （四角から上矢印が飛び出ているアイコン）をタップします。
3. メニューから **「ホーム画面に追加」** をタップします。
4. 右上の「追加」をタップすると、ホーム画面にアイコンが追加されます。

### 🤖 Android (Chrome) の場合
1. Chrome でアプリの URL を開きます。
2. 画面右上の **「︙（3点リーダー）」** をタップします。
3. **「ホーム画面に追加」** （または「アプリをインストール」）をタップします。
4. ホーム画面に追加されたアイコンから起動してください。

## 🛠️ 技術スタック

- HTML5 / Vanilla JavaScript
- **CSS**: Tailwind CSS (CDN)
- **アイコン/フォント**: Roboto Mono
- **ライブラリ**: html2canvas (タイムラインの画像出力に使用)
- **PWA**: manifest.json と Service Worker の動的生成に対応
