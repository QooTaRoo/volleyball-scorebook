# 🏐 Volleyball Scorebook PWA

バレーボールの試合をスマートフォンで簡単に記録・管理できるPWA（Progressive Web App）です。
面倒なインストールは不要で、ブラウザから開いて「ホーム画面に追加」するだけですぐにネイティブアプリのように使えます。

## ✨ 主な特徴

- **スマホに最適化された巨大スコア表示**: 屋外や体育館でも見やすい、高コントラストなダークテーマ。
- **直感的な試合開始セットアップ**: 
  - 試合開始時に「対戦チーム」「試合形式（1/2/3/5セット）」「目標点数」「初回のサーブ権」をまとめて設定可能。
  - 2セットマッチ（合計得失点差での勝敗判定）などの特殊ルールにも対応。
- **タイムアウト・カウントダウンタイマー**: 
  - タイムアウト取得時に自動でタイマーがポップアップ。残り時間を視覚化し、終了時にはバイブレーションでお知らせ。
- **コート図・ローテーション管理**:
  - コート上の配置を瞬時に確認し、タップして控え選手との交代（メンバーチェンジ）も可能。
- **詳細モード (Advanced Stats Mode)**:
  - **選べる入力形式**: 従来の「ラジアルメニュー（一筆書き）」に加え、直感的で操作ミスの少ない**「ダイアログ形式」**を新搭載（初期デフォルト有効）。設定画面からいつでも切り替え可能です。
  - **即時タップ起動**: 詳細スタッツモード有効時は長押しタイマー（200ms）を待たずにタップで即時ダイアログが開き、意図しない簡易得点登録を防止。
  - **コート対称レイアウト**: 選手グリッド（3x2）および得点原因ボタンは、ネットを中央に挟み、得点原因ボタンが常にバックロー（後衛）の外側になるよう、コートの反転状態に合わせて自動で対称配置されます。
  - **スマホ操作の最適化**: 縦画面時は「決定」「簡易得点」「キャンセル」ボタンが常に操作しやすい画面最下部に固定されます。
- **誤終了防止確認 ＆ 1タップUndo (Match-End Safety & Combined Undo)**:
  - **確認ダイアログ**: 最終セットの勝ち点が決まった際に終了確認ダイアログを表示し、誤操作による強制終了を防ぎます。「キャンセル」した場合はスコアを維持して試合画面に戻れます。
  - **1タップUndoの統合**: 終了確認キャンセル後に「Undo」を1回クリックするだけで、セット終了状態と勝利点（25点目など）の両方を同時に再帰処理で巻き戻し、正しいスコア（24点など）から即座にやり直せます。
  - **セット終了後の誤加点ガード**: セット勝利条件（例: 25-23）が満たされている間は、追加の得点ボタン入力を無視（早期リターン）し、誤タップによる26点目以降への不要な加点を完全に防止します。
- **試合分析・履歴の視認性向上 (Visual & Readability Improvements)**:
  - スマートフォンの画面でもはっきりと読めるよう、試合分析や履歴タイムラインのフォントサイズを一律大きく見直し。
  - 暗い背景での視認性向上のため、暗かったグレーテキストや極小テキストを高コントラストの明るいカラーに変更。
  - 選手詳細パネル内の各項目（Spike/Block/Ace/Error）をスタッツ固有のカラー（緑・青・黄・赤）に色分けし、瞬時にデータを判別可能に。
  - スマホでの改行崩れを防ぐため、ローテーション分析の見出しラベルを「ローテ 1 (#1)」のようにスッキリ短縮・最適化。
- **マイチーム機能 (My Team Stats Optimization)**:
  - チームマスター画面でチームに「マイチーム」のマークを付与可能。
  - アプリ設定に**「マイチームのみ詳細入力可」**トグルを新設。ONにすると、非マイチーム側（相手チーム）のポイント時は選手選択画面が自動スキップされ、スコア記録の手間を大幅に軽減します（OFFのときは従来通り両チームのスタッツを記録可能）。
- **登録メンバー数上限の撤廃 (Dynamic Team Roster)**:
  - チームメンバーの14名上限を完全撤廃。何人でもメンバーを追加・登録可能。
  - 各選手行に個別削除用のゴミ箱アイコンを追加し、「+ メンバーを追加」ボタンでの動的追加に対応。オンコートメンバー維持のための最低6名バリデーションやダミー自動補完機能も完備。
- **メインメニュー (Navigation Hub)**: 
  - 起動時に「新規試合」「試合再開」「履歴」「設定」を俯瞰できるメニュー画面を追加。
  - 12時間以上の無操作で自動的にメニューに戻るセッションチェック機能を搭載。
- **インタラクティブタイムライン & 過去得点の修正・動的再計算**: 
  - 各セットの得点推移やタイムライン of 得点ブロックを直接タップして修正できる機能。
  - 過去の任意の得点の「得点チーム」「得点原因」「対象選手」を修正すると、**それ以降のサーブ順、ローテーション、スコア、セット勝敗、選手交代などを時系列順にすべて瞬時に完璧に動的再計算**します。
  - 試合履歴や分析結果を、1枚の画像としてLINEなどで簡単に共有。
- **データ管理（インポート/エクスポート）**:
  - 登録チームや試合履歴をJSON形式でバックアップ・復元可能。機種変更時もデータを引き継げます。
- **プロフェッショナルなUI**: 
  - `Lucide Icons` を採用し、直感的で洗練されたインターフェース。
  - 画面を極限までシンプルにするため、スコア画面のボタン類をメインメニューに集約。
  - タイムライン画面上部のボタン群をアイコンのみに変更し、縦画面（ポートレート）での改行やレイアウト崩れを防ぐデザインに最適化。
  - 縦画面（対面レイアウト）と横画面（左右分割）の自動切り替えに対応。

## 📱 使い方（基本操作）

- **メインメニュー**: アプリを起動すると表示されます。「新規試合開始」で設定ダイアログに進みます。
- **スコア記録**: 自分のチームのエリアをタップすると得点が入ります。
- **詳細入力（ラジアルメニュー）**: 画面を長押しして指をずらす（一筆書き）ことで、選手別のスタッツを記録できます。
- **過去スコアの修正**: 試合中、統計ボタン（グラフアイコン）からタイムラインを開き、誤入力した過去の得点ブロックをタップすることで、得点チームやスタッツを修正し、サーブ順等の整合性を保ちながら動的再計算を行えます。
- **各種メニューへのアクセス**: スコア画面中央の「...」ボタンをタップするとメインメニューに戻ります。
- **画像シェア**: タイムラインや分析画面の「共有」ボタンから、記録を画像として保存・送信できます。

## 🚀 インストール方法 (PWA)

このアプリはPWAに対応しており、スマホのホーム画面に追加してフルスクリーンで利用できます。

### 🍎 iPhone / iPad (Safari) の場合
1. Safari でアプリの URL を開きます。
2. 画面下部の「共有」アイコン（四角から上矢印）をタップ。
3. メニューから **「ホーム画面に追加」** を選択。

### 🤖 Android (Chrome) の場合
1. Chrome でアプリの URL を開きます。
2. 画面右上の「︙（3点リーダー）」をタップ。
3. **「ホーム画面に追加」** （または「アプリをインストール」）を選択。

## 🛠️ 技術スタック

- **Core**: HTML5 / Vanilla JavaScript
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Lucide Icons
- **Libraries**: html2canvas (画像生成), Lucide (アイコン)
- **Persistence**: LocalStorage / FileReader API (バックアップ)
- **Testing**: Vitest / JSDOM (ローカルテストスイート)

## 🧪 テストの実行方法

新機能の追加やリファクタリング時にデグレードが発生しないよう、論理機能をテストする「Vitest ユニットテスト」と、実ブラウザ上でのボタンのクリック性（z-indexの重なり順など）や画面遷移を自動検証する「Playwright E2Eテスト」の2つのテストスイートが導入されています。

### 1. 依存関係のインストール
テスト用のモジュール（Vitest / JSDOM / Playwright）をインストールし、E2Eテストに必要なブラウザバイナリをセットアップします。
```bash
# モジュールのインストール
npm install

# Playwright用ブラウザのインストール
npx playwright install chromium
```

### 2. テストの実行

#### A. ユニット・インテグレーションテスト (Vitest)
以下のコマンドで全37個のユニット・インテグレーションテストを実行します。
```bash
# 1回のみ実行する場合
npm run test:run

# ウォッチモード（変更監視）で実行する場合
npm run test
```

#### B. E2E（実ブラウザ動作）テスト (Playwright)
以下のコマンドで、ヘッドレスブラウザ上で実際のUI対話（新規試合開始ダイアログのクリック、スタメン交代、ポジション入れ替えなど）を検証します。z-indexなどの重なりによるボタン反応の有無も自動で検証されます。
```bash
# E2Eテストを実行する（自動でローカルサーバーが起動します）
npm run test:e2e
```
