# Suggested Commands

Commands to develop, test, and run the project.

## Development & Test Commands
- **Run Unit/Integration Tests**: `npm run test:run`
- **Run Unit Tests (Watch mode)**: `npm run test`
- **Run E2E Tests (Playwright)**: `npm run test:e2e`
- **Serve local files**: `npx -y serve -l 8282 --no-port-switching .` (runs the project locally; also used by Playwright webServer hook).
